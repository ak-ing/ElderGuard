# 长辈守护（ElderGuard）

[![构建](https://github.com/ak-ing/ElderGuard/actions/workflows/build.yml/badge.svg)](https://github.com/ak-ing/ElderGuard/actions/workflows/build.yml)

帮家里长辈的安卓手机挡掉快应用和流氓应用，记下谁在弹广告、新装了什么，交给家人从源头处理。

- **不联网**：没有联网权限，所有记录只存在这台手机上。
- **长辈无感**：长辈只看到一个「守护中」的大字页面，不用做任何判断。
- **家人做主**：标记、卸载、冻结都在家人密码之后。
- **开源可审计**：代码都在这里，安装包由 GitHub Actions 从源码自动构建。

## 它做什么

只按确定的事实动手，不猜「这是不是长辈自己点的」：

| 看到什么 | 怎么处理 |
|---|---|
| 快应用来到前台 | 自动返回（家人可以在家人页关掉这条规则） |
| 家人标记为流氓的应用来到前台 | 自动返回 |
| 不在前台的应用在别的应用上面弹出悬浮窗 | 记录，交给家人处理 |
| 全屏弹出的通知，或「手机中毒」「恭喜中奖」「内存不足」这类通知 | 记录；流氓应用发的直接撤掉 |
| 新装了一个应用 | 记下时间和来源（哪个商店、安装包文件……），附上它的风险信号 |
| 有应用索要 Shizuku 高级权限 | 挡掉（家人正在维护时除外） |
| 打开应用商店、其他普通应用 | 不拦、不记，长辈可以正常下载和使用 |

家人页里还有：

- **手机体检**：找出开着无障碍、是设备管理器、桌面上没有图标、名字像清理加速工具的应用，以及没关的开发者选项、USB 调试、无线调试。
- **维护模式**：借助 [Shizuku](https://shizuku.rikka.app/) 临时获得 adb 权限，直接冻结、卸载流氓应用，收回它的悬浮窗、通知和后台运行。结束时自动关闭无线调试，30 分钟没有操作也会自动结束。
- **守护自检**：自动打开一次快应用，看守护在这台手机上能不能挡掉，生成可以发给开发者的报告。
- **分享报告**：生成一张近 7 天的周报图片，发到家人群。

## 安装

1. 到 [Releases](https://github.com/ak-ing/ElderGuard/releases) 下载最新的 `ElderGuard-x.y.z.apk`，传到长辈手机上安装（需要允许「安装未知应用」）。
2. 打开后跟着设置向导走，**请由家人完成**：
   1. 设置 6 位家人密码；
   2. 开启无障碍服务（必须），建议再开通知使用权和发送通知；
   3. 选择守护方式：「自动挡掉」（默认）或「仅记录」；
   4. 首次体检：看看手机里已经装了哪些可疑应用。
3. 设置完成后跑一次 **家人页 → 守护自检**，确认守护在这台手机上有效。

部分手机省电时会关掉守护。遇到这种情况，在家人页的权限里打开「不限制耗电」和「允许自启动」，再把长辈守护在最近任务里锁定。

> 1.1.0 起发布签名换成了 CI 专用签名。装过更早版本的手机需要先卸载再安装，原来的记录和密码会清空。

### 只从这里下载

官方安装包只在本仓库的 [Releases](https://github.com/ak-ing/ElderGuard/releases) 发布，由 GitHub Actions 从源码构建并签名。
别处下载的「长辈守护」可能被人改过。不放心时可以在电脑上核对签名：

```bash
apksigner verify --print-certs ElderGuard-x.y.z.apk
```

输出里的证书 SHA-256 应该是：

```
6e8a15d3e64efb46f02b8e219b592788617bb86b8452e4354d13e79c735b6919
```

不一致就不要安装。

## 权限

| 权限 | 用来做什么 |
|---|---|
| 无障碍服务 | 知道前台是哪个应用、屏幕上有哪些悬浮窗，执行「返回」。不接收点击和输入事件，读不到长辈打的字 |
| 通知使用权（可选） | 发现可疑通知，撤掉流氓应用的通知 |
| 发送通知 | 守护被系统关掉时提醒 |
| 查询已安装的应用 | 显示应用名称，体检扫描 |
| 振动 | 密码键盘的按键震动 |
| 忽略电池优化（可选） | 减少守护被省电策略关掉 |
| Shizuku（仅维护模式） | 冻结、卸载、收回权限 |

另外，WorkManager 库会自动带上唤醒锁、开机广播、前台服务、读取网络状态这几个权限，用来每 15 分钟检查一次守护是否还在运行。读取网络状态只能查看有没有联网，不能联网。

**没有联网权限**：App 不能上传任何数据。自检报告、周报图片都由家人自己决定发给谁。

## 已知限制

- 不能触摸的悬浮窗不在系统给无障碍服务的窗口列表里，发现不了。
- 没被家人标记的应用，如果靠整页界面自己跳出来弹广告，不会有记录。不过装它时、它弹悬浮窗或全屏通知时都会有记录，体检也能看到它申请的能力；家人标记以后它再出现就会被挡。
- 应用被「强行停止」时，系统会同时关掉它的无障碍服务和提醒，App 自己察觉不到，只能等下次打开时首页显示「守护未开启」。

## 从源码构建

需要 JDK 17 和 Android SDK（compileSdk 37）。

```bash
./gradlew :app:testDebugUnitTest :app:lintRelease :app:assembleRelease
```

没有签名配置时，release 包不签名，只能用来确认能编译。需要本地签名时，在根目录放一个 `keystore.properties`（已在 `.gitignore` 里）：

```properties
storeFile=/path/to/release.jks
storePassword=...
keyAlias=...
keyPassword=...
```

## 发版

由 GitHub Actions（[`.github/workflows/build.yml`](.github/workflows/build.yml)）自动完成：

- 推送 `main` 或提 PR 时：单测、Lint、打包，APK 在那次运行的 Artifacts 里。
- 推送 `v*` 标签时：先检查标签和 `versionName` 一致，用仓库 Secrets 里的发布签名打包，建 Release 并附上 APK。

```bash
# 先改 app/build.gradle.kts 里的 versionCode / versionName
git tag v1.1.0
git push origin v1.1.0
```

发布签名放在仓库 Secrets：`KEYSTORE_BASE64`、`KEYSTORE_PASSWORD`、`KEY_ALIAS`、`KEY_PASSWORD`。
